## 版本线

```text
上游主线   4.2.3 ──── 4.2.4 ──── 4.3.0 ──── 4.3.1 ──── 4.4.0 ──── 4.4.1 ──── 4.4.2 ──── 4.5.0 ──── 4.5.1 ──── 4.5.2 ──── 4.5.3
                    │
分支       4.2.3-Speed ──────────────────────────────────────────────────────────────────────────────────────► 4.5.3-Speed
```

- 版本号 = 上游基线版本 + `-Speed` 后缀
- `blender_manifest.toml` 的 `version` 只能是纯 `X.Y.Z`（扩展校验要求），分支标识写在 `__init__.py`
- 详细规则见 `4.5.3-Speed 合并与临时数据管理更新说明.md` 第四节

# GoB 4.5.3-Speed 更新说明：合并上游 4.5.3 + 临时数据管理

| 项目 | 内容 |
|---|---|
| 更新日期 | 2026-11-23 |
| 分支版本 | `4.5.3-Speed`（上游基线 v4.5.3） |
| 适配环境 | Blender 4.2+ / 5.2.1 LTS，ZBrush 2022–2026 |
| 涉及文件 | `__init__.py`、`blender_manifest.toml`、`ui.py`、`preferences.py`、`utils.py`、`paths.py`、`geometry.py`、`gob_import.py`、`gob_export.py`、`gob_s_import.py`、`temp_data.py`（新增）、`docs/`（新增） |

## 一、本次更新的三件事

1. **合并上游 4.5.3**：从 4.2.3 一路追平到 4.5.3（含 4.2.4、4.3.x、4.4.x、4.5.0–4.5.3 的全部修复与优化）。
2. **新增「临时数据管理」子面板**：统计 GoZ 中转目录大小、按白名单清理临时文件。
3. **彻底改为分支版本**：分支名 `Gob_Speed`，版本号统一为「上游版本 + `-Speed`」，manifest、插件名、`gob_version()` 全部体现分支身份，更新日志集中到 `docs/`。

---

## 二、合并方式

不是「覆盖文件」，而是在临时仓库里做三方合并：

```text
base    = 上游 v4.2.3（09-06-2025）   ← 分叉点
fork    = 本分支 4.2.3-Speed          ← 当时的实测修复版
upstream= 上游 v4.5.3（09-16-2026）
```

`git merge upstream` 后逐个解决冲突，原则是：**上游的技术重构全盘吸收，分支的实测修复与界面改造重新落位**。
冲突文件 7 个：`__init__.py`、`blender_manifest.toml`、`geometry.py`、`gob_export.py`、`gob_import.py`、`preferences.py`、`ui.py`。

### 2.1 上游 4.2.3 → 4.5.3 的主要变化

| 版本 | 关键变化 |
|---|---|
| 4.2.4 | 适配 ZBrush 2026.1.1 目录变化；修正 macOS 默认路径 |
| 4.3.0 | 蒙版导出三选项；无面集时导出不报错；非拉丁字符对象名处理 |
| 4.3.1 | 三角化/应用修改器不再丢面集与蒙版；修复混合拓扑导出的 UV 偏差 |
| 4.4.0 | 轴重映射（任意轴 → 任意轴，并可单独翻转） |
| 4.4.1 | 导出时移除非 ASCII 名称（分支未采用，见 §5） |
| 4.4.2 | 多边形组校验更稳健 |
| 4.5.0 | 拓扑一致时保留骨骼顶点组；轴重映射互为逆运算；缩放修正；`.sculpt_face_set` 兼容 |
| 4.5.1 | 高面数网格导入导出性能与内存优化 |
| 4.5.2 | ZBrush 细分级别回传修复；Windows/macOS 双路径设置；视图层内外对象重导入修复 |
| 4.5.3 | 未知块不再吞掉后续数据；纹理缺失仍完成导入；畸形数据安全处理 |

上游导入器此时已重构为「函数式 + 按块长度读取」（`_read_goz_section()` 等），
块头 16 字节、`载荷 = 块总长 - 16`，与本分支在 S导入里验证过的规则一致 —— 这也是双方能顺利对齐的前提。

### 2.2 分支改动在新代码上的落位

| 文件 | 分支改动 | 落位方式 |
|---|---|---|
| `gob_import.py` | 中文对象名 | 上游 `_read_goz_object_name()` 仍用 `string.printable` 过滤（中文被整段丢弃），改为「保留可打印字符 + 去 NUL」，空名回退 `GoZ_Mesh` |
| `gob_import.py` | UV 按面配对 | 新增模块级 `_pair_uvs_to_mesh()`：面数一致时走上游的向量化快路径；面数不一致（`validate()` 删过面）时按「面顶点元组」配对写入 |
| `gob_import.py` | 多边形组越界保护 | 上游已用 `min(声明数, 载荷数, 网格面数)` 截断，删除分支旧补丁 |
| `gob_export.py` | 中文名 UTF-8 长度域 | 上游改为「ASCII 编码失败 → `escape_object_name()` 重命名对象」；分支改为 `obj.name.encode("utf-8")`，并删除重命名逻辑（不再改用户对象名） |
| `gob_export.py` | 无面对象提示 | 上游只在 `MESH` 分支提示；分支补到曲面/曲线/文字/元球分支，并释放临时网格 |
| `gob_export.py` | 项目路径分隔符 | 新增 `_normalized_project_path()`：手填目录没有结尾 `/` 时补齐，避免拼出 `...Default中模体型5` |
| `gob_s_import.py` | S导入 | 原样保留；路径刷新改调 `paths.set_goz_path_from_preferences()`（上游 4.5.x 的平台路径机制） |
| `ui.py` | 侧栏面板 | 保留 `VIEW3D_PT_goB`；同时恢复上游顶栏按钮 `draw_goz_buttons()`，二者并存 |
| `geometry.py` | 曲线可导出 | 保留分支行为（导出时判断是否有面），不采用上游「曲线必须有倒角/挤出」 |
| `preferences.py` | 全中文界面 | 以上游 4.5.3 新结构（含双平台路径、轴重映射）为基重做汉化，并追加版本号显示 |

## 三、新增功能：临时数据管理

### 3.1 位置

`3D 视图 > 侧栏（N 面板）> GoB > 临时数据管理`（子面板，默认折叠）。
通过 `bl_parent_id = "VIEW3D_PT_goB"` 挂在主面板下。

### 3.2 统计范围

| 目录 | 取法 | 内容 |
|---|---|---|
| 交换目录 | `utils.get_project_path()` | `GoZProjects/Default` 下的 `.GoZ`、`.bmp`、`.ztn`、`GoB_variables.zvr` |
| GoZBrush | `utils.get_pixologic_path()/GoZBrush` | ZBrush 写回的 `.GoZ` 副本、残留 `.ztl`、配置与可执行文件 |

统计为「目录顶层文件」求和（中转文件都写在顶层，不递归），显示：总大小 / 文件数 / 可清理大小。

### 3.3 清理规则

```text
白名单后缀：.goz  .ztl  .ztn  .bmp
保护对象：  GoZ_*.txt、GoZ_Config.bak、GoZ*.exe、其它任意文件
附加条件：  修改时间早于「保留时长」（默认 1 小时）
```

- 白名单写死在 `temp_data.TEMP_SUFFIXES`，**永远不会**删除配置与可执行文件
- 「保留时长」防止删掉 ZBrush/Blender 正在读写的中转文件；被跳过的数量会在结果里报出
- 清理范围：`交换目录 + GoZBrush` / `仅交换目录` / `仅 GoZBrush`

### 3.4 交互流程

1. 启动 1 秒后自动统计一次（只读）→ 面板打开即有数据
2. 「统计大小」按钮手动刷新；显示统计时间
3. 「清理临时文件」→ 先弹确认框（`将删除 N 个文件，释放 X MB`）→ 确认后删除 → 自动重新统计 → 报告释放量
4. 每个目录右侧「打开」按钮在系统文件管理器中定位

### 3.5 新增/改动的代码对象

| 对象 | 类型 | 说明 |
|---|---|---|
| `temp_data.py` | 新模块 | 统计、清理、子面板、操作符 |
| `VIEW3D_PT_goB_temp_data` | 面板 | 「临时数据管理」子面板 |
| `gob.temp_scan` | 操作符 | 统计两个目录 |
| `gob.temp_clean` | 操作符 | 确认后清理 |
| `gob.temp_open_folder` | 操作符 | 打开目录（`EXCHANGE` / `GOZBRUSH`） |
| `Scene.gob_temp_min_age` | 场景属性 | 保留时长（小时） |
| `Scene.gob_temp_scope` | 场景属性 | 清理范围 |

## 四、分支版本化

| 位置 | 值 | 说明 |
|---|---|---|
| `blender_manifest.toml` `version` | `4.5.3` | 扩展校验只接受纯 `X.Y.Z`，不能带后缀 |
| `__init__.py` `BRANCH_NAME` | `Gob_Speed` | 分支名（插件名/说明里使用） |
| `__init__.py` `VERSION` / `BRANCH_TAG` | `(4, 5, 3)` / `"Speed"` | 单一来源；版本号 = 上游版本 + `-Speed` |
| `__init__.py` `VERSION_STRING` | `4.5.3-Speed` | 面板/首选项显示 |
| `bl_info["name"]` | `Gob_Speed (GoB 分支版)` | 传统安装方式下的插件名 |
| manifest `name` / `tagline` | `Gob_Speed (GoB 分支版)` / 含「Gob_Speed 分支版」 | 扩展列表里可区分 |
| `utils.gob_version()` | `4.5.3-Speed` | 写入 GoZ 变量文件第 6 项 |

两个坑（均已处理）：

1. **扩展安装时 Blender 不注入 `bl_info`**。原 `gob_version()` 靠 `addon.bl_info["name"] == "GoB"` 在 `addon_utils.modules()` 里查找，
   改名后必然 `IndexError`；现改为从 `sys.modules[__package__]` 取本模块的 `VERSION_STRING`。
2. **`preferences.addons[...].module` 是包装模块**，取不到 `VERSION_STRING`（实测返回 `None`），所以不能用它。

## 五、与上游的两处刻意差异

| 差异 | 上游做法 | 分支做法 | 理由 |
|---|---|---|---|
| 非 ASCII 对象名导出 | 4.4.1 起：ASCII 编码失败就 `escape_object_name()` **重命名对象** | 按 UTF-8 字节写名称块，**不改名** | 改名会污染用户场景（`中模体型5` → `Object`）；本分支已实测 Blender→ZBrush 2026→Blender 往返名称、几何、UV 全部正常。理论上仍有 ZBrush 版本挑剔名称块的风险，届时手动改英文名即可 |
| 曲线的导出可用性 | 曲线没有倒角/挤出就禁用导出按钮 | 按钮始终可用，导出时判断，无面则弹窗说明 | 禁用按钮不告诉用户原因；提示框能直接说「该对象转换后无面」 |

顶栏按钮与侧栏面板并存属于**功能叠加**，不是取舍：两处调用同一批操作符。

## 七、使用注意

1. **必须重启 Blender**，扩展才会重新加载。
2. 以前用普通导入进场景的模型若 UV 有问题，重新导入一次即可（4.2.3-Speed 已修的旧问题，与本次合并无关）。
3. 上游 4.5.x 的轴设置变了：`翻转上轴/翻转轴向前` 变成 `重映射 X/Y/Z 轴 + 单独翻转`，
   旧首选项里的这两项不会迁移，请按需在新面板里重设。
4. 清理默认只删「1 小时以前」的中转文件；正在传输时可先点「统计大小」确认再清理。
5. 清理不会碰 `GoZ_ObjectList.txt`、`GoZ_Config.txt`、`GoZ_ProjectPath.txt`，ZBrush 配置安全。

## 八、回滚方法

| 目标 | 操作 |
|---|---|
| 回到 4.2.3-Speed | 用本次更新前的备份覆盖插件目录：`%APPDATA%\Blender Foundation\Blender\5.2\gob_backup_4.2.3` |
| 只回滚临时数据管理 | 删除 `temp_data.py`，并从 `__init__.py` 的 `classes` 与 `register()` 里移除相关项 |
| 只回滚上游合并 | 用备份中的 `gob_import.py` / `gob_export.py` / `geometry.py` / `preferences.py` / `paths.py` / `utils.py` 覆盖，并恢复 `__init__.py` |
| 回滚版本标识 | `BRANCH_TAG = ""`，`VERSION_STRING` 自动变成 `4.5.3`；同时把 manifest 的 `name`/`tagline` 改回上游文案 |
